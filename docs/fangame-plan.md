## 二、二创前提：《白紙のエトワリア》

### 核心构想

原作最終章叫「終わってから始まる物語」。这个标题本身就是二创的授权书 —— 本企划接在它之后。

设定推演，每一步都扣着原作规则：

1. 原作规则：エトワリア 的居民靠**阅读聖典**汲取クリエ 而活。
2. 于是：聖典不需要被毁掉。**只要没人再读，クリエ 就会枯竭。**
   ハイプリス 想烧掉聖典而失败了；而「不再有人翻开」这件事，安静地做到了她做不到的事。
3. 所以本作的危机不是毁灭，是**遗忘**。世界不会爆炸，只会**变白**。

**原创术语（一个，且只有一个）：「白紙化」**
当一位クリエメイト 的聖典页面长久无人阅读，她会先失去颜色，再失去轮廓，最后回到白紙。
她没有死 —— 死需要有人记得。她只是**没有可以回去的那一页了**。

> 表现上直接复用仓库已有的渲染能力：模型逐步去饱和 → 材质转白 → alpha 溶解。
> 这不是新美术，是给现有着色器加一个参数。

### 玩家是谁

**「読み手」** —— 最后一个还在读聖典的人，来自聖典之外。

这不是加设定，是把原作规则读到底：クリエ 本来就来自「被阅读」，
那么阅读者站在世界之外，恰好是这套系统本来的形状。玩家不是勇者、不是神官，
只是**还记得的人**。这是全篇唯一的原创角色定位，且刻意不给立绘、不给台词 —— 玩家就是玩家。

### 主要角色的位置（全部沿用原作性格与关系）

- **きらら** —— 仍能感知**絆**。但世界变白后，她感知到的絆越来越少，
  这对她是最残酷的设定：她的天赋变成了一个计数器，只会往下走。
- **ランプ** —— 女神候補生。她熟读聖典，于是她是全世界最先发现「哪一页开始变白」的人。
- **マッチ** —— 负责让沉重的场面还能笑出来。原作的它就是这个功能，不改。
- **アルシーヴ** —— 掌管**図書館**。取材于离线版只保留了「キャラクター一覧、図書館、オプション」这件事。
  第一部她封印了女神，第二部之后她成了那个把书一本本收好的人。全篇最重的角色由她承担。
- **ソラ** —— 女神。她只在最终章正面出场，说一件事：**聖典本来由神书写，从今往后由读者书写。**
- **住良木 うつつ** —— 不存在于任何聖典的少女。因为不在聖典上，**她是唯一不会白紙化的人**。
  于是她成了见证者：所有人都在褪色，只有她完好无损地记得全部过程。

### 反派

**不复活ハイプリス 当坏人。**原作已经完成了她的弧线，把她再拉出来打一次是对原作的浪费。

真正的对手是**忘却本身**，具象为**「白紙の獣」** —— 由白紙化的残片聚合而成的东西。
它没有台词、没有恶意、没有目的。它只是像水一样填满没人再看的地方。
（战斗素材直接取仓库现有 604 个 enemy 模型，做去色处理。）

而ハイプリス 若出场，位置是**证人**：她曾想毁掉聖典，如今亲眼看见聖典自己变白。
她最有资格说出那句话 —— 原来我错的不是想法，是以为那需要我动手。

### 结局

不能让世界「恢复原状」—— 那是廉价的，也不诚实：服务确实结束了。

结局是：**読み手 在最后一页空白上，写下第一行字。**
不是神写的聖典，是读者写的。ソラ 认可这次交接。
世界不会回到从前，但**只要还有人写下去，它就还在**。

最后一幕：镜头从エトワリア 拉远，变成一本正在被合上的书 ——
然后再被翻开。标题浮现：**「終わってから始まる物語」**（借用原作最終章标题作为收束）。

### 边界声明

- 沿用原作：世界、女神、クリエ / 聖典 / クリエメイト 体系、全部角色性格与关系、五职业六属性、时间轴战斗。
- 本企划新增：「白紙化」现象、「読み手」视角、「白紙の獣」敌役、以及故事发生在最終章之后这一时间点。
- **不做**：不给原作角色安排原创恋爱线、不改角色性格、不推翻原作结局、不复活已完结的反派当 boss。

## 四、玩法提案（四个方向，任选或组合）

全部为纯静态、无后端、可直接 GitHub Pages 部署。素材按需懒加载，所以总量大不是问题。

### 提案 A：《白紙のエトワリア》—— 时间轴战术 RPG（复刻原作战斗）

把原作那套时间轴战斗真的做出来。

- **战斗**：5 人小队，时间轴 ATB。图标到右端者行动，行动后按指令消耗值后退 —— 强指令后退更多，
  这是原作的核心取舍，也是整套系统好玩的原因。
- **指令**：通常攻撃 ＋ クラススキル1/2 ＋ ぶきスキル。
  **正好对应仓库已有的 `idle / attack / class_skill_1 / class_skill_2 / class_skill_3` 五个动画。**
  也就是说战斗动画零成本 —— 这是选 A 的最大理由。
- **とっておき**：攻击累积计量槽，满了放大招。**スタンゲージ**：受击累积，满则昏迷。
- **属性克制**：炎→風→土→水→炎 环形，陽⇄月 互克。已有六个属性图标。
- **白紙化机制（本作原创）**：己方角色有「色彩值」。受到白紙の獣 攻击会掉色，
  掉到 0 则该角色**当场变白退场**，且**本章内不可再用**。
  救回来的方式不是加血，是「思い出す」—— 消耗回想值，念出她聖典里的一句话。
  → 让原作的治疗职（そうりょ）在本作有了新的、且符合主题的定位。
- **编队**：从 685 张卡里选，職業/属性/作品 三重筛选，直接复用 `cards.js`。

**成本**：高。战斗系统是从零写的状态机 + 结算 + AI。
**复用**：模型加载器、表情系统、武器挂载、class-actions、BGM、685 张卡数据全部现成。
**适合**：想要「这就是きらファン」的手感。

---

### 提案 B：《図書館の灯》—— 章节制 ADV（视觉小说）

把重心全部压在剧本和演出上，不做战斗。

- 3D 模型当立绘用：站位、表情切换、动作演出、口型/点头。仓库的表情系统已经能做到。
- 每章一首 BGM，官方语音在关键台词处播放（已有 title-voice 与 gacha 语音）。
- 章节间插入「図書館」界面：翻开一本变白的聖典，看着它恢复文字。
- 分支极少（2〜3 处），保证剧本质量而不是分支数量。

**成本**：低。真正的成本在写剧本，代码量小。
**复用**：模型/表情/BGM/语音全部现成。
**适合**：剧情优先，想要最快看到完整成品。风险最低。

---

### 提案 C：《思い出すまで》—— 记忆解谜 / 図書館 Roguelite

- 図書館 是一座正在变白的塔，每层随机生成，由变白的房间构成。
- 每层给你一条**残缺的聖典句子**，从你已收集的角色里选出「说这句话的人」。
  选对 → 该角色恢复颜色并入队；选错 → 这一页彻底白紙化，本次探索永久失去她。
- 谜题数据可从 685 张卡的作品/职业/属性/角色关系直接程序化生成，也可手写精选题。
- 每次探索结束，把找回的记忆存入図書館（localStorage 长期积累）。

**成本**：中。核心循环简单，重点在题库设计。
**复用**：卡数据、模型、図書館 UI。
**适合**：想要可重复游玩、且「阅读＝力量」这个主题被做成实际机制的方案。
**风险**：本质是知识问答，对不熟悉きらら 作品的玩家门槛偏高。

---

### 提案 D：《エトワリア再構築》—— 3D 城镇经营 / 博物馆

- 一座变白的エトワリア 城镇，玩家逐步点亮。
- 收集クリエ（阅读聖典获得）→ 修复建筑 → 修好的建筑里住进对应作品的角色 → 角色恢复颜色。
- 角色在城里走动、日常互动、随时间/天气变化（`bgm_town_*` 已有 5 首＋圣诞＋新年）。
- 本质是一座**可以走进去的纪念馆**，接续仓库现有 memorial 页面的思路，但从 2D 升级为 3D 空间。

**成本**：中高。3D 场景与寻路是新增工作，且仓库没有城镇场景模型（只有角色/敌人/武器）——
**这是 D 的硬伤：场景得自己搭。**
**适合**：想要氛围与长期陪伴感，而不是挑战性。

## 五、我的建议

**B ＋ A 的组合，分两期做。**

理由：
- B 先做，是因为这个企划的价值在**剧情**。「世界因为没人读而变白」这件事，
  必须靠文本讲清楚，玩法讲不清楚。而 B 的代码成本最低，能最快得到一个完整、能给人看的成品。
- A 后做，是因为 `idle/attack/class_skill_1..3` 这套动画已经在仓库里躺着了。
  不把时间轴战斗做出来，这批素材最有价值的部分就浪费了。
- 两者天然嵌套：B 的章节结构里本来就留了战斗段落。第一期战斗用一次性演出过场顶住，
  第二期换成真战斗，剧本一行都不用改。

C 和 D 更适合当二期之后的追加内容（C 可以作为図書館 的小游戏，D 作为收集展示）。

## 六、语言方案（已定：中文 ＋ 日文）

全部文本双语。这跟仓库现状是一致的 —— `cards.js` 里每张卡本来就带 `name / nameZh / nameEn`，
沿用同一套字段习惯即可。

### 数据结构

剧本每一行是一个对象，`ja` 与 `zh` 并列，不做运行时翻译：

```js
{ id: "p-012", speaker: "lamp", face: "surprised",
  ja: "……このページ、文字が薄くなってます",
  zh: "……这一页的字，变淡了" }
```

`speaker` 取角色 id，显示名同样双语（`ランプ` / `兰普`），从角色表取，不写死在剧本里。

### 显示模式（三档，玩家可切）

| 模式 | 表现 | 面向 |
| --- | --- | --- |
| `zh` | 只显示中文 | 默认。读起来顺 |
| `ja` | 只显示日文 | 配合官方语音，还原度最高 |
| `both` | 日文在上（小字）＋中文在下 | 想对照原文的人 |

语音始终是日文（官方素材只有日文），所以 `both` 模式下日文行与语音对得上，
中文行作为字幕 —— 这也是最贴近「玩日文游戏配中文补丁」的体验。

### 翻译原则

- **专有名词在中文行用中文，不留片假名/日文汉字。** 这条推翻了本文早先的写法
  （原本写的是「保留原文汉字/片假名」）。实际把序章跑起来之后，
  中文行长这样：「読み手。是読み手吗。読み手！！」——
  中文读者看到的不是「保留原文的味道」，是**排版坏了**。
  官方中文服本来就给了每个词的译名，用它们就对了。
- **译名一律取官方数据，不自己造。** 来源：
  `https://trans.kirafan.cn/zh.json`（1214 条）与 `asset/gacha/cards.js` 的
  `characterZh`。已确认：

  | 日文 | 中文 | 来源 |
  | --- | --- | --- |
  | きらら | 琪拉拉 | `characterZh` |
  | ランプ | 兰普 | `characterZh` |
  | アルシーヴ | 阿尔希芙 | `characterZh` |
  | ソラ | 索拉 | `characterZh` |
  | クリエ | 克利耶 | zh.json 的「克利耶梅特」（クリエメイト） |
  | 聖典 | 圣典 | 简化字形 |
  | 絆 | **羁绊** | 不能写「绊」——「绊」在中文里是绊倒，不是纽带 |
  | マッチ | 玛琪 | **本企划自拟**，官方无译名，已在 `cast.js` 注明 |
  | 言の葉の樹 | 言叶之树 | 官方无条目，取社群通用写法 |
  | 読み手 | 读者 | 官方无条目（本企划自创的概念），中文取「读者」 |

### 序章设计说明

- **アルシーヴ 第一个出场**：她在原作第一部封印了女神，是把书收好的人。
  让她来解释「白紙化」规则，比让主角组解释更有重量。
- **ランプ 那个问题**（「你还记得多少」）是全篇的题眼。她不是在寒暄，
  她在确认这一页还能撑多久。
- **きらら 的絆能力被反用**：原作里是找到同伴的天赋，这里变成计量流失的仪器。
  没有改她的设定，只是让同一个设定在新处境下自己产生残酷性。
- **マッチ 的插话不是凑数**：ランプ 激动那段如果不打断，序章会太沉。
  原作的マッチ 就是干这个的。
- **读者不给立绘不给台词**：所有人对着镜头说话。玩家不是角色，玩家是玩家。
